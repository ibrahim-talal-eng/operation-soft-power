# OPERATION: SOFT POWER

A small browser strategy game about American cultural diplomacy, 1956 to 1962. Plain HTML, CSS and JavaScript modules, no build step.

Run: `python3 -m http.server 8080`, then open http://localhost:8080
Test: `npm test` (Node 20+)
Deploy: push to GitHub and enable Pages on the root folder.

Event photos are loaded from Wikimedia Commons. If one fails to load, it is simply hidden.
